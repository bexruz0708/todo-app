# Todo App

This is a simple Todo application where users can create, edit and delete tasks and also drag and drop tasks.

## Features

- Add new tasks
- Search the task
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Login
- Logout
- Register
- Dark mode& Light mode

## Tech Stack

- JavaScript
- Python
- Django
- RestApi
- React
- Node.js
- Express
- MongoDB

## Installation

1. Clone the repository

git clone https://github.com/username/todo-app.git

2. Install dependencies

npm install

3. Run the project

npm start
